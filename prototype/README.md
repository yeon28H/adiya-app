# 어디야? — 함께 가고, 무사히 도착하고.

모임이 끝난 뒤 비슷한 방향으로 귀가하는 사람들을 연결하고, 마지막 한 사람의 도착까지 확인하는 귀가 동행 서비스 (시연용 MVP).

## 실행 방법
빌드 도구나 패키지 설치가 필요 없습니다. 이 폴더에서 정적 서버만 띄우면 됩니다.

```bash
cd ai-work/prototype
python -m http.server 5173
# 브라우저에서 http://localhost:5173 접속
```

## 구조
```
index.html          앱 셸
css/styles.css      디자인 시스템 (Warm Yellow & Cream 변수)
js/stations.js      수도권 지하철역 목업 데이터 (지도 API 대체)
js/matching.js      규칙 기반 매칭 엔진 (방향 40 + 목적지 거리 25 + 출발 시간 20 + 동행 구간 15)
js/store.js         데이터 계층 = 백엔드 역할 (localStorage 목업 API)
js/ui.js            라우터, 화면 렌더링, 이벤트
tests/e2e.html      E2E 테스트 (iframe으로 실제 클릭·입력 시뮬레이션)
tests/seed.html     시연 상태를 만들어 원하는 화면으로 이동 (?to=dash|match|register|planb|settings)
```

## 시연 시나리오
1. 메인에서 **1분 시연 체험하기** (또는 모임 만들기 → 초대 코드 → 시연용 친구 불러오기)
2. 내 귀가 정보 등록 → 매칭 결과(그룹·점수·이유) 확인 → 그룹 참여
3. 귀가 시작 → 대시보드에서 **시연: 도착 처리**로 친구들을 진행 → 도착 완료
4. 마지막 사람까지 도착하면 전체 귀가 완료 화면

## 부가 기능 (MVP, API 없이 시연 가능)
- **막차 위험 알림 · 출발 권장 시간**: 교통수단별 막차(시연 기준 목업)와 출발 예정 시간을 비교해 여유/임박/놓칠 수 있음을 표시하고, 귀가 전 그룹에 알려요.
- **단계별 안부 확인**: 예상 도착 시간이 지나면 ① 본인에게 확인 알림 → ② 응답이 없으면 지정한 안부 대상(기본: 주최자)에게 요청 → ③ 응답에 따라 상태 갱신. 도착이 늦은 것만으로 위험으로 단정하지 않아요.
- **자동 도착 감지**: 목적지 근처 진입을 시뮬레이션하고, 본인이 확인하면 도착 처리해요.
- **실시간 위치 대신 ETA 공유**: 이동 중인 참여자는 위치 대신 "도착까지 약 N분"만 보여요.
- **해산 매니저**: 귀가 시작/도착/혼자 귀가/확인 필요/막차 위험/마지막 미도착/미등록 현황과 등록 요청.

시연 중에는 내 카드의 **시연** 버튼(목적지 근처 자동 감지, 예상 도착 시간 지난 상황)으로 위 흐름을 바로 볼 수 있어요.
